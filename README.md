# Prestige Client — Injector Source

Source Code

Minecraft

An unofficial injector designed exclusively to inject the Prestige Client mod into Minecraft. The Prestige mod is built directly into the injector and is the only mod it supports.

## Features

* Prestige Only — Exclusively injects the built-in Prestige Client mod.

* Built-in Mod — No separate Prestige mod download required.

* Minecraft Integration — Designed to load Prestige into Minecraft.

* Source Code — Available for inspection and modification.

## Installation

1. Clone or download this repository.

2. Open the project in your development environment.

3. Review the source code and dependencies.

4. Follow the build instructions provided in the repository.

## Compatibility

* Game: Minecraft

* Mod: Prestige Client

* Supported mods: Prestige only

* Mod delivery: Built into the injector
